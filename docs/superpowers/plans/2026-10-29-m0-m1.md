# Shadow Clash M0–M1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Prove a playable, server-authoritative private 1v1 match in two independent browsers.

**Architecture:** A pure shared fixed-tick simulation owns movement and combat. Node/Socket.IO owns rooms, seats, validated inputs and snapshots. Phaser displays snapshots and captures keyboard input; accessible HTML supplies room controls and the HUD.

**Tech Stack:** Strict TypeScript, npm workspaces, Phaser 4, Vite, Node LTS, Socket.IO 4, Vitest, Playwright.

**Spec:** `PRD.md` and `AGENTS.md`, M0–M1 only. The user explicitly authorized implementation; use the supplied approved design and conservative defaults without another approval gate.

## Global Constraints

- 60 Hz headless authoritative simulation; snapshots approximately 20 Hz.
- 1280 × 720 logical arena; White/Black labeled placeholder shapes.
- 100 HP, 100 guard, light punch damage 5; A/D move, W jump, J punch, L block.
- No client-supplied position, damage, health or winner; constrained sequential input only.
- Maximum two humans, cryptographically random room codes and seat credentials.
- Local loopback services only. No deployment, final art, AI, queue or full M2 mechanics.

## Review Focus

- Blur/hidden tabs must release held controls and not leave a fighter moving.
- Rapid button changes must not create held-button attack spam.
- Malformed events, missing acknowledgements and duplicate room requests must not crash or steal seats.
- Room isolation, bounded resource cleanup and disconnect must prevent stale combat.
- Simultaneous hits, round transitions and reset must produce one shared official result.
